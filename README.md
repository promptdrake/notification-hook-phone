# Notification Hook Phone

  <img src="https://raw.githubusercontent.com/promptdrake/notification-hook-phone/refs/heads/main/Screenshot%20From%202026-07-29%2002-40-28.png" alt="Notification Hook Phone Banner">

A lightweight **Android (Kotlin)** application that listens to Android notifications and forwards them to your **existing backend API** in real-time.

This project is designed for developers who need to integrate Android notifications into their own infrastructure without relying on third-party services.

# Features

- Listen to Android notifications using `NotificationListenerService`
- Forward notifications to your own backend
- Lightweight background service
- Simple permission management
- Select which applications should be monitored

---

# Requirements

- Android 8.0+
- Notification Access permission
- Background running permission
- Existing backend API endpoint (Create Your own, and read every request arrived from app, they can be dynamic)


---

# Installation

Download the latest APK from the Releases page.

https://github.com/promptdrake/notification-hook-phone/releases/tag/app
Install the APK, grant the required permissions, configure your backend endpoint, and enable the service.
